# .NET 桌面 WPF 开发 — 概念对照表

| .NET 桌面体系 | JS/Node 体系 | 核心记忆 |
| :--- | :--- | :--- |
| .NET | Node.js | 运行平台 + 工具链，执行代码、编译打包 |
| C# | JavaScript | 编程语言，既能写界面逻辑，也能写后端业务 |
| WPF | Vue | 界面框架；WPF = 桌面 GUI；Vue = Web 网页 GUI |
| XAML | HTML | 界面标记；XAML 交给 WPF 引擎；HTML 交给浏览器引擎 |
| NuGet | npm | 包管理器，拉第三方库 |

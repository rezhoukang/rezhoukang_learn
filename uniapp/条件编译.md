# 条件编译

## 什么是条件编译？

> 在不同的端（平台）展示不同的代码。

UniApp 最大的优点是一套代码发布到多端（App、小程序、Web），但不同端的 UI 和能力不同，需要**条件编译**来控制哪些代码在哪个端生效。

---

## 语法

写在 `pages/` 目录下的任意 `.vue` 文件的 `<template>` 中。

```vue
<!-- 例如：pages/index/index.vue → 首页 -->
<!-- 只在 H5 端显示 -->
<template>
    <view>
        <view>这行在所有端都显示</view>
        <!-- #ifdef H5 -->
        <view>这行只在 H5 端显示</view>
        <!-- #endif -->

        <!-- #ifdef APP-PLUS -->
        <view>这行只在 App 端显示（iOS + 安卓）</view>
        <!-- #endif -->

        <!-- #ifdef MP-WEIXIN -->
        <view>这行只在微信小程序端显示</view>
        <!-- #endif -->

        <!-- #ifdef H5 || MP-WEIXIN -->
        <view>这行在 H5 和微信小程序都显示</view>
        <!-- #endif -->
    </view>
</template>
```

---

## 平台标识

| 标识 | 平台 |
|------|------|
| `APP-PLUS` | App（iOS + 安卓） |
| `H5` | Web 端 |
| `MP-WEIXIN` | 微信小程序 |
| `MP-ALIPAY` | 支付宝小程序 |
| `MP-BAIDU` | 百度小程序 |
| `MP-QQ` | QQ 小程序 |
| `MP-TOUTIAO` | 头条小程序 |

---

## 完整示例

```vue
<template>
    <view>
        <!-- #ifdef H5 -->
        <view class="bg-image">H5 端的背景图</view>
        <!-- #endif -->

        <!-- #ifdef APP-PLUS -->
        <view class="bg-image">App 端的背景图（显示在信号栏位置）</view>
        <!-- #endif -->
    </view>
</template>
```

## 进阶：APP-PLUS 无法区分 iOS 和安卓

`#ifdef APP-PLUS` 会在 iOS 和安卓都生效，无法单独区分。

**如果需要区分 iOS 和安卓（比如支付方式不同），要用 API 判断：**

```vue
<script setup>
import { ref, onMounted } from 'vue'

const platform = ref('')

onMounted(() => {
    // 获取当前设备的平台
    const res = uni.getSystemInfoSync()
    platform.value = res.platform  // "ios" 或 "android"
})
</script>

<template>
    <view>
        <view v-if="platform === 'ios'">iOS 设备 — 走 App Store 支付</view>
        <view v-if="platform === 'android'">安卓设备 — 走微信/支付宝支付</view>
    </view>
</template>
```

> `uni.getSystemInfoSync().platform` 返回值：`ios`、`android`、`mac`、`windows`、`linux`

## 面试题

### Q1：有一段代码想在某一端展示，该怎么办？

**回答：** 用条件编译 `#ifdef` / `#endif`。

### Q2：如果还想区分 iOS 和安卓呢？

**回答：** 条件编译无法区分 iOS 和安卓，需要调用 `uni.getSystemInfoSync().platform` 来判断设备平台。

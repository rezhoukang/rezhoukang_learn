## 一、Template — 视图层

**标签区别（和 Vue 不一样的地方）：**

| Vue | UniApp |
|-----|--------|
| `<div>` | `<view>` |
| `<span>` | `<text>`（支持 `selectable` 属性，长按可复制） |
| `<img>` | `<image>` |
| `<a>` | `<navigator>` |

## 二、Style — 样式层

**尺寸单位用 RPX（响应式 px）：**

- UI 设计稿宽度为 **750px** 时，量出来的尺寸直接写 `xxxrpx`
- 布局**都用 rpx**，不用 px，rpx 会自动根据屏幕宽度缩放
- 如果设计稿不是 750px，可以在工具（如蓝湖）里改成指定宽度

```
设计稿量出来 300px → 写 300rpx
设计稿量出来 100px → 写 100rpx
```

# 传值

## 一、页面传值（URL 参数）

A 页面跳转时，在 URL 后加 `?key=value` 传递：

```javascript
uni.navigateTo({
    url: `/pages/search/search?key=${this.key}&id=111`
})
```

B 页面在 `onLoad` 中通过 `options` 接收：

```javascript
onLoad(options) {
    console.log(options.key)   // 拿到传过来的值
    console.log(options.id)    // 111
}
```

> ⚠️ `onShow` 接收不到参数，必须在 `onLoad` 里接。

## 二、页面间传值（uni.$emit / uni.$on）

场景：从 A 跳到 B 选话题，选完返回 A，A 显示选中的结果。

### B 页面 — 传

```javascript
uni.$emit('selectedTopic', name)
//         ↑ 事件名         ↑ 传的值（比如"话题三"）
uni.navigateBack()                  // 返回上一页
```

### A 页面 — 接

```javascript
onShow() {  // 用 onShow，返回时 onLoad 不触发
    uni.$on('selectedTopic', (res) => {
    //       ↑ 事件名必须一致   ↑ 收到的值（"话题三"）
        this.selectedName = res
    })
}
```

| | 发出 | 接收 |
|--|------|------|
| API | `uni.$emit('事件名', 值)` | `uni.$on('事件名', callback)` |

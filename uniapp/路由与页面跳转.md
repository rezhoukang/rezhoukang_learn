# 路由与页面跳转

## 新建页面必须配置

在 `pages/` 目录下新建页面后，必须在 `pages.json` 中注册：

```json
{
    "pages": [
        {"path": "pages/index/index", "style": {}},
        {"path": "pages/list/list", "style": {}}   // 新增的页面
    ]
}
```

> 不配置的话，页面跳转不生效，也不报错。

---

## API 跳转方法

| 方法 | 效果 | 能否返回 |
|------|------|---------|
| `uni.navigateTo({url})` | 保留当前页，跳转到新页面 | ✅ 可返回 |
| `uni.redirectTo({url})` | 关闭当前页，跳转到新页面 | ❌ 不可返回 |
| `uni.reLaunch({url})` | 关闭所有页面，跳转到新页面 | ❌ 不可返回 |
| `uni.switchTab({url})` | 自动跳转到 tabBar 页面（手动的可以直接在pages.json配置） | ✅ |
| `uni.navigateBack({delta})` | 返回上一页（delta=1 返回上一页，delta=2 返回上两页） | ✅ |

```javascript
// navigateTo — 保留当前页跳转（最常用）
uni.navigateTo({ url: '/pages/list/list' })

// redirectTo — 关闭当前页跳转
uni.redirectTo({ url: '/pages/list/list' })

// reLaunch — 关闭所有跳转
uni.reLaunch({ url: '/pages/list/list' })

// switchTab — 自动 tabBar 页面
uni.switchTab({ url: '/pages/list/list' })

// navigateBack — 返回上一页
uni.navigateBack({ delta: 1 })
```

---

## ⚠️ switchTab 特别注意

- **跳转到 tabBar 页面**必须用 `uni.switchTab()`
- 用 `navigateTo` / `redirectTo` 跳 tabBar 页面会**不生效**
- 非 tabBar 页面用其他方法都可以

```
要跳的目标是 tabBar 页面 → 用 switchTab
要跳的目标不是 tabBar 页面 → 用 navigateTo 等
```

## 内置组件跳转

用 `<navigator>` 组件，和 API 方法效果一一对应：

```vue
<navigator url="/pages/list/list" open-type="navigate">
    跳转到列表页（可返回）
</navigator>

<navigator url="/pages/list/list" open-type="redirect">
    跳转到列表页（不可返回）
</navigator>

<navigator url="/pages/list/list" open-type="switchTab">
    跳转到 tabBar 页面
</navigator>

<navigator url="/pages/list/list" open-type="reLaunch">
    关闭所有跳转
</navigator>

<navigator open-type="navigateBack" delta="1">
    返回上一页
</navigator>
```

| 属性 | 作用 |
|------|------|
| `url` | 跳转路径 |
| `open-type` | 跳转方式（navigate / redirect / switchTab / reLaunch / navigateBack） |

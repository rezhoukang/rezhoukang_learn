# 生命周期

## 页面 vs 组件

| | 页面 | 组件 |
|--|------|------|
| 位置 | `pages/` 目录下 | `components/` 目录下 |
| 页面生命周期 | ✅ 有 | ❌ 没有 |
| 组件生命周期 | ✅ 也有 | ✅ 有 |

> `pages/` 下的 `.vue` 文件**既有页面生命周期，也有组件生命周期**。
> `components/` 下的 `.vue` 文件**只有组件生命周期**，没有页面生命周期。

---

## 页面生命周期

| 生命周期 | 触发时机 | 常用场景 |
|---------|---------|---------|
| `onLoad(options)` | 页面加载时触发（**第一次**进入页面） | 接收传参、请求展示类接口 |
| `onShow` | 页面显示时触发（**每次**进入页面都执行） | 从其他页面返回时需要刷新列表 |
| `onReady` | 页面初次渲染完成 | 获取 DOM（类似 Vue 的 mounted） |
| `onHide` | 页面隐藏（跳转到其他页面时） | 隐藏弹框/蒙层 |
| `onUnload` | 页面卸载（关闭页面时） | 清理资源 |

- **接收参数** → `onLoad(options)`（onShow 接不到参数）

### onReady — 获取 DOM

```javascript
// onShow 时 DOM 可能还没渲染完，拿不到
onShow() {
    console.log(this.$refs.content)  // undefined
}

// onReady 时 DOM 已经渲染完成，可以拿到
onReady() {
    console.log(this.$refs.content)  // <view>...</view>
}
```

### onHide — 隐藏弹框

从 A 页面跳转到 B 页面，返回时弹框不应该还显示着：

```javascript
onHide() {
    this.showPopup = false  // 页面隐藏时关掉弹框
}
```

## 组件生命周期

和 Vue 标准生命周期相同：

| 生命周期 | 说明 |
|---------|------|
| `beforeCreate` | 实例初始化前 |
| `created` | 实例创建完成 |
| `beforeMount` | DOM 挂载前 |
| `mounted` | DOM 挂载完成 |
| `beforeUpdate` | 数据更新前 |
| `updated` | 数据更新后 |
| `beforeUnmount` | 实例销毁前 |
| `unmounted` | 实例销毁完成 |

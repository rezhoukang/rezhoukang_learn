# 跨域处理

## 策略

```
本地开发 → Vite 处理跨域
生产环境 → Nginx 处理跨域
后端     → 不处理跨域
```

## 开发环境（Vite）

`vite.config.ts` 中配置代理：

```ts
export default defineConfig({
    server: {
        proxy: {
            '/api': {
                target: 'http://localhost:8080',
                changeOrigin: true
            }
        }
    }
})
```

## 生产环境（Nginx）

```nginx
location /api/ {
    proxy_pass http://library-backend:8080;
    # 转发到后端，由 Nginx 做代理，不存在跨域问题
}
```

## 为什么后端不处理？

因为跨域是**浏览器**的同源策略限制，不是后端的问题。

- 开发时：Vite 代理转发，前端请求走 Vite → 后端
- 生产时：Nginx 反向代理，前后端同源（同一个域名/端口）

两种方式都绕过了跨域，后端加 `@CrossOrigin` 反而多此一举。

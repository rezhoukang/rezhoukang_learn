# 环境配置思路

## 架构

```
开发：本地服务（除 redis 用 Docker）
生产：全走 Docker
Nginx：独立容器，供多项目共用
```

## 三个 env

| 文件 | 用途 | 值 |
|------|------|-----|
| `env.dev` | 开发，接本地 | 真实值 |
| `env.prod` | 占位符 | `${变量}` |
| `env.docker` | yml 引用，传给容器 | 真实密码 |

## 关键点

- 开发环境本地跑，生产环境全走 Docker，yml 不存密码
- Nginx 独立，因为不止一个项目用
- frontend 容器只构建，产物进 volume，Nginx 直接读

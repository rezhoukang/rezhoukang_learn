# Linux 目录结构详解

> 核心思想：**Linux 一切皆文件**，目录按功能分类存放，不能乱删乱改。

## 六大核心目录

| 目录 | 作用 | 类比 Windows |
|------|------|-------------|
| `/` **根目录** | 所有目录的起点，系统必备 | "此电脑" |
| `/bin` **命令目录** | 存放 `ls`、`cd`、`pwd` 等系统必备命令 | 系统工具库 |
| `/etc` **配置目录** | 存放网络、用户、软件等配置文件 | 控制面板 |
| `/home` **用户家目录** | 每个普通用户的家目录，如 `/home/test` | `C:\Users\` |
| `/root` **管理员家目录** | 超级管理员 root 的专属目录 | 管理员桌面 |
| `/var` **可变数据目录** | 存放日志、缓存、数据库等动态文件 | 日志文件夹 |
| `/usr` **软件目录** | 用户安装的软件存放位置（如 Python、Nginx） | `C:\Program Files` |

## 其他常用目录

| 目录 | 作用 |
|------|------|
| `/boot` | 系统内核和启动文件，**删了无法开机** |
| `/dev` | 硬件设备文件（如 `/dev/sda` 硬盘） |
| `/tmp` | 临时文件，重启自动清空 |
| `/mnt` | 挂载 U 盘、移动硬盘等外设 |

## ⚠️ 新手注意事项

- **`/bin`、`/etc`、`/boot`** 是核心目录，**千万不要乱删**
- 修改 `/etc` 下的配置文件前**先备份**
- 普通用户只能操作自己 `/home` 下的内容
- `/tmp` 里的文件重启后自动消失，不用担心占空间
- `/usr/bin` 其实是 `/bin` 的快捷方式（软链接）

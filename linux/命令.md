# Linux 常用命令

## 文件操作
- `ls` — 列出文件
- `cd` — 切换目录
- `pwd` — 当前路径
- `mkdir` — 创建目录
- `rm` — 删除（-r 递归）
- `cp` — 复制
- `mv` — 移动/重命名
- `touch` — 创建文件
- `cat` — 查看文件内容

## 权限
- `chmod` — 修改权限
- `chown` — 修改所有者

## 进程
- `ps` — 查看进程
- `top` — 资源监控
- `kill` — 结束进程

## 网络
- `ping` — 网络连通测试
- `curl` — HTTP 请求
- `netstat` — 网络状态

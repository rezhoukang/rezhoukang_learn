# Redis

**Redis** = 内存数据库，读写极快。常用于缓存、并发锁、计数器等。

**本质理解：** Redis ≈ 一个独立部署的 Java 服务，里面就一个 `Map<String, Object>`。A 模块发 HTTP 请求往里存，B 模块发 HTTP 请求往外取——它就是分布式系统里的"公共变量"。

## 主要用途

| 用途 | 说明 |
|------|------|
| **缓存** | 热点数据放 Redis，减轻 MySQL 压力 |
| **分布式锁** | 多服务争抢资源时保证互斥 |
| **会话存储** | 登录态共享 |
| **计数器** | 原子自增点赞数、访问量 |

## 原子性 vs 锁

- **单条命令有原子性**，多条命令组合则没有
- 多条命令操作 → 需要**锁**保证原子性
- **乐观锁**：冲突少时用，冲突多则频繁重试
- **悲观锁**：冲突多时用，抢不到直接放弃
- 原子性管单条命令，锁管多条命令组合

## 集群模式

集群 = 拷贝。跟硬盘 RAID 一样——RAID 1 是把数据完整复制一份做镜像备份，对应 Redis 主从复制，主挂了从能顶上；RAID 0 是把数据拆开分散到多块盘，对应 Redis 分片集群，多台机器分摊读写压力。

## Redis + MySQL 配合

```
读：Redis 有 → 直接返回 | 没有 → 查 MySQL → 写回 Redis
写：先写 MySQL → 删 Redis 缓存（下次读时刷新）
```

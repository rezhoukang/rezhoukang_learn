# 数据库设计基础

```sql
-- 不冲突，每个表都有自己的 id，各管各的：
-- ============================
-- 1. 主键：唯一标识一行
-- ============================
CREATE TABLE dept (
    id INT PRIMARY KEY AUTO_INCREMENT,  -- 主键，自增
    name VARCHAR(50)
);

-- ============================
-- 2. 普通字段：存数据
-- ============================
CREATE TABLE user (
    id INT PRIMARY KEY,
    name VARCHAR(50),      -- 普通字段
    age INT                -- 普通字段
);

-- ============================
-- 3. 外键：关联其他表
-- ============================
CREATE TABLE employee (
    id INT PRIMARY KEY,
    name VARCHAR(50),
    dept_id INT,                                    -- 外键
    FOREIGN KEY (dept_id) REFERENCES dept(id)       -- 关联 dept 的 id
);

-- ============================
-- 4. 联合主键：多字段组合唯一
-- ============================
CREATE TABLE score (
    student_id INT,
    course_id INT,
    score INT,
    PRIMARY KEY (student_id, course_id)   -- 两个字段一起做主键
);
```
实际开发比较少用外键，通常是写在业务代码

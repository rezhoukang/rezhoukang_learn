# Spring Boot 新建项目要勾选的

用 IDEA 或 start.spring.io 新建项目时勾上这三个：

| 分类 | 勾选 | 有什么用 |
|------|------|---------|
| Web | **Spring Web** | 内嵌 Tomcat + SpringMVC，有它才能写 @RestController |
| SQL | **MyBatis Plus** | 不用写 SQL，继承 BaseMapper 自带增删改查，自带分页 |
| SQL | **MySQL Driver** | 连接 MySQL 数据库 |
| Developer Tools | **Lombok** | @Data 省写 getter/setter |

或者手动在 pom.xml 加 MyBatis Plus（Spring Initializr 官方可能没收录 MP）：

```xml
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-spring-boot3-starter</artifactId>
    <version>3.5.9</version>
</dependency>
```

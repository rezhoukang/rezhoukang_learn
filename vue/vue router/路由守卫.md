# 路由守卫

路由守卫 = Vue Router 自带的拦截器。跳转前检查"能不能去"。

## 必会：全局前置守卫（90% 场景够用）

```ts
// router/index.ts
import { createRouter, createWebHistory } from 'vue-router'

const router = createRouter({
  history: createWebHistory(),
  routes: [
    { path: '/', component: Home },
    { path: '/login', component: Login },
    { path: '/admin', component: Admin, meta: { requiresAuth: true } },
  ],
})

// 每次跳转前触发
router.beforeEach(async (to) => {
  if (!to.meta.requiresAuth) return                        // 不需要登录 → 放行

  try {
    const res = await axios.get('/api/auth/me', { withCredentials: true })
    if (!res.data) return '/login'                         // 未登录 → 踢去登录页
  } catch {
    return '/login'
  }
})

export default router
```

**关键：** `to.meta.requiresAuth` 标记哪些页面需要登录，`axios.get('/api/auth/me')` 靠后端 httpOnly cookie 验证身份（前端不碰 token）。

## 了解即可

| 守卫 | 触发时机 |
|------|----------|
| `router.afterEach` | 跳转之后（打点统计，不拦截） |
| `beforeEnter`（路由内） | 进某条路由之前（很少用，`beforeEach` 够） |
| `onBeforeRouteLeave`（组件内） | 离开当前页时（"有未保存确定离开？"） |
| `onBeforeRouteUpdate`（组件内） | 参数变了但组件没换（`/user/1` → `/user/2`） |

## 生产环境

token 存 **httpOnly cookie**（后端设置），前端 JS 读不到，XSS 拿不走。

```ts
// api/auth.ts
export async function getCurrentUser() {
  const res = await axios.get('/api/auth/me', { withCredentials: true })
  return res.data   // 有用户信息 = 已登录，null = 未登录
}
```

## 工程化拆分（可选）

```ts
// router/routes/admin.ts
export default [
  { path: '/admin', component: Admin },
]

// router/index.ts — 汇总
import adminRoutes from './routes/admin'
const router = createRouter({ routes: [...adminRoutes] })
```

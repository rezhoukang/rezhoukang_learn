# Vue Router 总结

## 一、路由工作模式

| 模式 | URL 例子 | 服务器需配置 |
|------|----------|-------------|
| **Hash** | `/#/home` | ❌ 不需要 |
| **History** | `/home` | ✅ 需要 fallback |

**Hash**：`#` 后的路径不发给服务器，刷新永远请求 `/` → 返回 `index.html` → Vue 自己解析。
**History**：路径全发给服务器，刷新时服务器不认识就 404 → 需配置 fallback（所有路径返回同一个 `index.html`）。

```js
// 开发时二选一
const router = createRouter({
  history: createWebHashHistory(),   // Hash → 带 #
  // history: createWebHistory(),    // History → 不带 #
  routes
});
```

### Nginx 配置

```nginx
# Hash 模式（无需额外配置）
server { listen 80; root /dist; }

# History 模式（必须加 fallback）
server {
    listen 80;
    root /dist;
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

`try_files` 尝试按顺序找文件，找不到就往后试：

1. 先找 `/home` 这个文件 → 没有
2. 再找 `/home/` 这个目录 → 也没有
3. 最后给 `/index.html` → Vue 自己处理路径

## 二、路由用法速览

| 特性 | 核心区别 / 作用 |
|------|----------------|
| **`to` 字符串 vs 对象** | 字符串写死路径；对象可传参、可用 `name` |
| **命名路由 `name`** | 路径变了不用改模板，传参更方便 |
| **嵌套路由 `children`** | 父路由内嵌子路由，实现页面局部变化 |
| **`query` 参数** | URL 以 `?key=val` 传参，直观 |
| **`params` 参数** | URL 以 `/path/:id` 传参，更简洁语义化 |
| **`props` 配置** | 把路由参数当 props 传给组件，解耦 |
| **`replace`** | 跳转不留历史记录，不能"后退" |
| **编程式导航** | 用 JS（`push/replace/back`）控制跳转 |
| **重定向 `redirect`** | 访问 A 路径自动跳转到 B 路径 |

# 组件

## 组件注册方式

```ts
// 全局注册：任何组件都能直接用，不用 import
import MyButton from './MyButton.vue'
app.component('MyButton', MyButton)

// 局部注册：只有当前组件能用
import MyButton from './MyButton.vue'
// 直接 import 后在 template 里用就行
```

**全局注册**方便但打包时会全部打进去；**局部注册**按需引入，推荐。

## 懒加载

路由懒加载就是最常见的懒加载，到达某条路由时才下载对应组件代码：

```ts
{
  path: '/admin',
  component: () => import('./Admin.vue'),   // 到达 /admin 才下载
}
```

`defineAsyncComponent` 用于非路由场景，比如弹窗组件不想影响首屏：

```ts
import { defineAsyncComponent } from 'vue'
const EditDialog = defineAsyncComponent(() => import('./EditDialog.vue'))
// 用户点了编辑按钮才下载，首屏不加载
```

## 动态组件

```vue
<Home />       <!-- 固定显示 Home，不能变 -->
<About />      <!-- 固定显示 About -->

<component :is="current" />
<!--         ↑ current = Home 时 → 显示 Home -->
<!--         ↑ current = About 时 → 显示 About -->
```

## KeepAlive — 保持组件存活

默认切换组件会销毁重建，`KeepAlive` 能缓存状态。

```vue
<KeepAlive>
  <component :is="current" />
</KeepAlive>
```

对比：

| | 没 KeepAlive | 有 KeepAlive |
|--|-------------|-------------|
| 切走 | 销毁 | 缓存 |
| 切回 | 重新创建 | 恢复原样 |
| 输入框内容 | 清空 | 保留 |

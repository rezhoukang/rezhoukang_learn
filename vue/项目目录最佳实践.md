# Vue 项目目录最佳实践

```
public/                       # 不经过打包，直接复制
  favicon.ico

src/
├── main.ts                    # 入口
├── App.vue                    # 根组件
├── views/                     # 页面
├── components/                # 组件
├── router/                    # 路由
├── store/                     # 状态
├── hooks/                     # 逻辑复用
├── utils/                     # 工具函数
├── types/                     # TS 类型
├── assets/                    # 资源（经过打包处理）
│   └── images/
└── styles/                    # 全局样式
```

## 原则

| 原则 | 说明 |
|------|------|
| **按功能分** | 路由/状态/类型/工具各归各类 |
| **按业务分** | views 按页面，components 按组件 |
| **不要过早拆分** | 文件少时放一起，大了再抽 |
| **名字即注释** | 文件名说清楚是干什么的 |

---

## `public/` vs `assets/`

```
public/    → 原样复制到 dist/，文件名不变，引用用绝对路径 /xxx
assets/    → 经 webpack 处理（压缩+哈希），引用用 @/xxx

<img src="@/assets/logo.png">       → 打包后 <img src="/assets/logo.abc123.png">
<img src="/favicon.ico">            → 打包后 <img src="/favicon.ico">（不变）
```

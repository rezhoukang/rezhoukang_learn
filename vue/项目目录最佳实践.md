# Vue 项目目录最佳实践

```
public/                       # 不经过打包，直接复制
  favicon.ico

src/
├── main.ts                    # 入口
├── App.vue                    # 根组件
├── views/                     # 页面
├── components/                # 组件
├── router/                    # 路由
├── store/                     # 状态
├── api/                       # 接口请求（axios/fetch 封装）
├── composables/               # 组合式函数（hooks）
├── utils/                     # 工具函数
├── types/                     # TS 类型
├── assets/                    # 资源（经过打包处理）
└── styles/                    # 全局样式
```

### 各目录关系

```
views/ 页面 → 调 components/ 组件
                         ↓
            composables/ 组合式函数（逻辑复用）
                 ↓
     utils/ 纯函数 ← store/ 全局状态
                 ↓
            api/ 接口请求（axios/fetch 封装）
```

- **views**：页面，组合多个组件拼成一个页面
- **components**：组件，调 composables 获取数据和方法
- **composables**：组合式函数，封装可复用的逻辑，内部可调 utils、store、api
- **api**：接口请求层，封装 axios/fetch，按模块拆分（如 `api/user.ts`），供 composables 调用
- **utils**：纯工具函数，不涉及 Vue 响应式，只做数据处理
- **store**：全局状态，所有组件/composables 都能读写

## `public/` vs `assets/`

```
public/    → 原样复制到 dist/，文件名不变，引用用绝对路径 /xxx
assets/    → 经 webpack 处理（压缩+哈希），引用用 @/xxx

<img src="@/assets/logo.png">       → 打包后 <img src="/assets/logo.abc123.png">
<img src="/favicon.ico">            → 打包后 <img src="/favicon.ico">（不变）
```

# Vue 3 组合式 API + `<script setup>`

## 完整示例（基础结构 + 响应式 + 事件 + 条件循环 + 双向绑定）

```vue
<script setup>
import { ref, reactive, computed } from 'vue'

// 响应式数据
const count = ref(0)
const msg = ref('你好')
const double = computed(() => count.value * 2)  // computed — 有缓存，依赖不变不重算
const getDouble = () => count.value * 2           // 普通函数 — 每次调用都重新算
const show = ref(true)
const list = ref(['苹果', '香蕉', '橘子'])
const inputVal = ref('')

// reactive：对象
const user = reactive({ name: '张三', age: 18 })

// 事件
const handleClick = (name) => alert('你好 ' + name)
</script>

<template>
  <!-- 双向绑定 -->
  <input v-model="inputVal" placeholder="输入">

  <!-- v-bind（简写 :）绑定属性 -->
  <button :disabled="count === 0" :style="{ color: count > 5 ? 'red' : 'blue' }">
    v-bind绑定属性
  </button>

  <!-- v-on（简写 @）绑定事件 -->
  <button @click="handleClick('张三')">点击</button>
  <button @mouseenter="msg = '鼠标进来了'" @mouseleave="msg = '鼠标走了'">hover我</button>
  <button @click="count++">加{{ count }}</button>

  <!-- 显示数据 -->
  <p>{{ msg }} - 双倍：{{ double }}</p>
  <p>{{ user.name }} - {{ user.age }}岁</p>

  <!-- 条件 -->
  <p v-if="show">v-if：显示中（销毁/创建）</p>
  <p v-show="show">v-show：显示中（只是隐藏/显示）</p>
  <button @click="show = !show">切换</button>

  <!-- 循环 -->
  <ul>
    <li v-for="(item, i) in list" :key="i">{{ item }}</li>
  </ul>
</template>
```

## 组件通信

```vue
<!-- 子组件 Child.vue -->
<script setup>
// props：父传子
const props = defineProps({ title: String, count: { type: Number, default: 0 } })
// emit：子传父
const emit = defineEmits(['update', 'delete'])
</script>

<template>
  <h3>{{ props.title }} - {{ props.count }}</h3>
  <button @click="emit('update', '新数据')">更新</button>
  <button @click="emit('delete', 1)">删除</button>
</template>
```

```vue
<!-- 父组件 -->
<script setup>
import Child from './Child.vue'
const onUpdate = (data) => console.log('收到：', data)
</script>

<template>
  <Child title="标题" :count="42" @update="onUpdate" @delete="id => console.log('删', id)" />
</template>
```

## 生命周期

```vue
<script setup>
import { onMounted, onUnmounted, onBeforeUnmount, onUpdated, onBeforeUpdate, onActivated, onDeactivated } from 'vue'

onMounted(() => console.log('组件挂载到 DOM 后'))
onUpdated(() => console.log('数据更新，DOM 重新渲染后'))
onBeforeUpdate(() => console.log('数据更新，但 DOM 还没渲染'))
onActivated(() => console.log('keep-alive 组件激活'))
onDeactivated(() => console.log('keep-alive 组件停用'))
onBeforeUnmount(() => console.log('组件销毁前一刻'))
onUnmounted(() => console.log('组件已销毁'))
</script>
```

## 监听
watch 就是"当某个东西变了，自动执行一段逻辑"。 不用你手动去调，也不用写事件。
```vue
<script setup>
import { ref, watch } from 'vue'

const keyword = ref('')

// 监听单个
watch(keyword, (newVal, oldVal) => {
  console.log(`从 ${oldVal} 变成 ${newVal}`)
})

// 监听多个
watch([keyword, count], ([newK, newC], [oldK, oldC]) => {
  console.log('keyword 或 count 变了')
})
</script>

# 组件通信

**`props/emit` + `v-model` + `slot` = 必学三件套**，剩下的统一 **Pinia 梭哈** 💪

## 1. Props / Emit — 父传子 + 子传父

```vue
<!-- 子组件 Child.vue -->
<script setup lang="ts">
// props：父传子，父组件传什么这里声明什么
const props = defineProps<{ title: string; count?: number }>()
// emit：子传父，子组件发事件父组件接收
const emit = defineEmits<{ update: [data: string]; delete: [id: number] }>()
</script>

<template>
  <h3>{{ props.title }} - {{ props.count }}</h3>
  <button @click="emit('update', '新数据')">更新</button>
  <button @click="emit('delete', 1)">删除</button>
</template>
```

```vue
<!-- 父组件 -->
<script setup lang="ts">
import Child from './Child.vue'
</script>

<template>
  <Child title="标题" :count="42"
    @update="data => console.log('收到：', data)"
    @delete="id => console.log('删', id)" />
</template>
```

## 2. v-model — 父子双向绑定

子组件改了值，父组件自动同步。`defineModel` 一行顶原先 props + emit 共 3 行。

```vue
<!-- 子组件 MyInput.vue -->
<script setup lang="ts">
const text = defineModel<string>({ required: true })
//          ↑ 泛型（尖括号）<string> 指定 v-model 的值是字符串类型
//            一行搞定双向绑定，原先要 props 声明 + emit 声明 + 模板事件，共 3 行
</script>

<template>
  <input v-model="text" />
</template>
```

```vue
<!-- 父组件 -->
<script setup lang="ts">
import { ref } from 'vue'
import MyInput from './MyInput.vue'
const text = ref('')
</script>

<template>
  <MyInput v-model="text" />
  <p>你输入了：{{ text }}</p>
</template>
```

## 3. Slot — 父组件往子组件塞内容

子组件挖坑（`<slot>`），父组件填坑。

```vue
<!-- 子组件 Card.vue -->
<template>
  <div class="card">
    <div class="card-header">
      <slot name="header">默认标题</slot>      <!-- 具名插槽：有名字的坑 -->
    </div>
    <div class="card-body">
      <slot>默认内容</slot>                    <!-- 默认插槽：没名字的坑 -->
    </div>
  </div>
</template>
```

```vue
<!-- 父组件 -->
<script setup lang="ts">
import Card from './Card.vue'
</script>

<template>
  <Card>
    <template #header>                         <!-- #name = v-slot:name -->
      <h2>自定义标题</h2>
    </template>
    <p>这是插进去的内容</p>                     <!-- 没写 #，自动填进默认插槽 -->
    <p>第二段</p>                               <!-- 也在默认插槽 -->
    <p>第三段</p>                               <!-- 全部按顺序塞进去 -->
  </Card>
</template>

<!-- 最终渲染结果：
     <div class="card">
       <div class="card-header">
         <h2>自定义标题</h2>          ← #header 替换了 <slot name="header">
       </div>
       <div class="card-body">
         <p>这是插进去的内容</p>       ← 默认插槽，三个 p 按顺序
         <p>第二段</p>
         <p>第三段</p>
       </div>
     </div>
-->
```

## 总结

1. **`defineModel`**：子传父、父传子双向绑定，但只能绑一个值。
2. **`defineProps` 和 `defineEmits`**：`defineProps` 是父传子，`defineEmits` 是子传父。
3. **`slot`**：只有父传子，子组件挖坑，父来填，父传子。
